01

Mainboard & Stacking

主導 LoRa / WiFi 雙模無線對講裝置的主機板佈局與堆疊架構開發，在固定的產品尺寸限制下，逐步優化零件配置密度與內部空間利用率。

  • 主機板佈局迭代: 定義三種配置方案(Type 1-3),針對不同尺寸目標與功能組合進行取捨，系統性地評估 PCB 面積利用率與熱管理路徑。
  • 堆疊架構設計: 比較 Wakie-talkie 原始堆疊與兩款新外形方案(UT Move Option A / B),定義 PCB、電池與天線的三維堆疊關係。
  • 穿戴外形研究: 探索穿戴式堆疊型態與泡棉外形方案，在電池續航、產品體積與人因配戴體驗之間取得平衡。
02

UniFi Hotel Ecosystem

延伸自 UT Move 的產品情境，定義了一整套 UniFi 飯店應用生態系，包含 UTP Touch Max、UA Hotel Reader、UC Control Dial、UniFi UGP 等各類裝置，建構完整的房間內外互動體驗。

  • UTP Touch Max: 前台或客房大螢幕觸控裝置，整合會議與環境控制。
  • UA Hotel Reader: 客房外門禁裝置，搭配 NFC 感應完成入住與識別。
  • UC Control Dial: 客房內情境控制旋鈕，快速切換燈光、音樂、空調模式。
  • UniFi UGP: 客房內大型觸控條，結合語音與情境同步。
03

Guest Journey

設計了兩種情境的完整使用者流程，涵蓋首次入住與回頭客的差異化體驗，讓整個入住過程無感、直覺，同時強化飯店的識別記憶。

  • 首次入住: 手機預訂 → 前往房間(無需櫃檯) → NFC 感應 Hotel Reader → 光影與聲音引導入房 → Control Dial 設定房內情境。
  • 退房與清潔提醒: 房客退房後,Reader 螢幕自動切換為「Clean the Room」提醒，啟動清潔流程。
  • 回頭客個人化: 二次入住時系統自動辨識，依上次使用行為預設燈光、音樂與環境情境，強化品牌記憶。
04

System Architecture

從裝置層級到情境層級，定義了一整套系統架構，確保各裝置能透過 UniFi Console/Switch/AP 統一協同運作。

  • 裝置分工: Console/Switch/AP 為核心，連接 TALK、GP、Control、Reader 各裝置類型，形成飯店級網通拓撲。
  • Before Check-in: 網頁或前台預訂 → 系統設定房號 → 啟動 Guest Point → 感應 Hotel Reader → 完成入住。
  • After Check-in: Control Dial 預設多種情境模式(燈光、窗簾、TV 頻道、音樂)供房客快速切換。
  • Check-out: 透過 Talk Max 接收外部提醒(含鬧鐘),使用房卡或手機感應 Hotel Reader 完成離房上鎖。
